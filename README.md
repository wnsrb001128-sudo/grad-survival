# 대학원에서 살아남기

뱀파이어 서바이벌류(뱀서라이크) 웹 게임. 대학원생이 석사 4학기를 버티고 취업하는 이야기입니다.

## 실행

- `index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다 (설치 불필요, 크롬·엣지 권장).
- 글꼴(Pretendard, Black Han Sans)은 인터넷에서 불러옵니다. 오프라인이면 맑은 고딕으로 표시됩니다.
- 조작: **WASD** 이동 (공격은 자동) · 캐릭터·무기·레벨업 카드 **1~4 / 클릭** · **ESC** 일시정지 · **M** 소리 켜기/끄기

## 캐릭터

게임 시작 → 캐릭터 → 시작 무기 순서로 고릅니다. 기본 패시브는 처음부터 켜져 있고 패시브 칸을 차지하지 않습니다.

| 캐릭터 | 시작 무기 (하나 선택) | 기본 패시브 |
|---|---|---|
| Dry lab (시뮬레이션 연구실) | 펜 · 마우스 · 키보드 · 개인 PC | 🗄️ 병렬 연산: 모든 무기 쿨타임 -8% |
| Wet lab (실험 연구실, 가운·고글) | 피펫 · 시약병 · 분젠 버너 · 실험쥐 | 🥼 실험 가운: 받는 피해 -1, 최대 멘탈 +10% |

- 전용 무기: 마우스·키보드·개인 PC는 Dry lab만, 피펫·시약병·분젠 버너·실험쥐는 Wet lab만 얻습니다. 펜·전공서적·파리채·클로드·GPT·제미나이는 공용.
- 파리채(공용 근접 무기): 늘 손에 들고 내가 바라보는(움직이는) 방향의 부채꼴(70°, 최대 90°)을 쉬지 않고 휘젓는다. 적을 알아서 노리지 않아 맞히기 어렵지만 한 대가 아주 세고(34, 진화 120), 그 부채꼴로 날아드는 일반 적의 탄을 막아 낸다 (보스가 쏜 탄은 진한 고리로 그려지고 못 막는다). 개수는 늘 1개 (투사체 +1 효과를 받지 않음).
- 게임 방법의 모든 탭은 주제별 색깔 상자로 묶어 보여 준다 (`js/ui.js` 의 `hsec`). 무기 탭은 공용 → Dry lab 전용 → Wet lab 전용 순서(청록 · 파랑 · 보라), 화면 보는 법은 화면 정보 · 내 캐릭터 상태 · 적 · 보스 특수 패턴(모양별) · 내 무기 효과 · 맵, 패시브는 기본 패시브 · 공격 · 생존 · 이동/성장, 적·보스는 웨이브마다 일반 적 · 보스 · 이벤트 시각표.
- 두 캐릭터 모두 웨이브가 바뀔 때마다 점점 지쳐 갑니다 (1차 생생 → 2차 밤샘 → 3차 번아웃 직전 → 4차 영혼 가출 → 박사 좀비).
- 맵도 캐릭터마다 다릅니다: Dry lab은 시뮬레이션 연구실(책상·모니터·서버), Wet lab은 실험 연구실(실험대·흄후드·냉동고·동물실).

## 규칙

| 웨이브 | 내용 | 보스 |
|---|---|---|
| 1차 · 석사 1학기 (0~4분) | 대학원 수업, 교수님 심부름, 개인 프로그레스 미팅, 중간고사 | 중간보스 감기, 보스 기말고사 |
| 2차 · 석사 2학기 (4~8분) | LA, TA, OA, 주간 랩미팅, 컴퓨터 강제 종료(윈도우 업데이트), 시험 채점, 플롯 그리기 | 중간보스 연구비 정산, 보스 과제 킥오프 미팅 |
| 3차 · 석사 3학기 (8~12분) | 과제 미팅, 메이저 리비전, 버그, 시뮬레이션 발산(NaN), 어학 성적 취득 | 중간보스 학회 논문 초록 작성, 보스 학회 포스터 발표 |
| 4차 · 석사 4학기 (12~16분) | 과제 제안서 작성, Reviewer #2, 마감, 취업 면접·학위논문 초고(탄을 쏘는 적) | 중간보스 학회 구두 발표 (4차 0:45), 최종 보스 졸업논문 심사 (4차 1:45) |

- 4차가 끝날 때 **연구 실적 40,000 이상 + 최종 보스(졸업논문 심사) 격파 → 취업 엔딩**. 하나라도 못 하면 **박사 과정** (시간 제한 없는 무한 웨이브)
- 보스·중간보스마다 특수 패턴이 있다 (바닥에 빨간 예고 지역이 차오른 뒤 터짐): 감기 재채기 · 기말고사 OMR 마킹 · 연구비 정산 엑셀 정산표(가로·세로 십자) · 킥오프 로드맵 발사·로켓 발진(화살표 띠를 따라 돌진) · 논문 초록 작성 마감 카운트다운(안쪽부터 터지는 고리 3겹) · 포스터 질문 행렬 · 구두 발표 레이저 포인터 · 졸업논문 심사 발표자 조명(조명 밖 전체가 터짐, 조명 안이 안전) · 과제 정기 보고 진도 체크(따라오다 멈추는 돋보기 표적) · 박사 심사 빨간펜·재심사 도장
- 박사 과정 보스 순서: 학회 포스터 발표 → 과제 정기 보고 → 학회 구두 발표 → 박사 학위 논문 심사 (48초 뒤 첫 보스, 이후 2분마다. 한 바퀴 돌면 처음부터, 나올 때마다 체력 배율 +60%)
- 최종 보스 졸업논문 심사는 체력이 절반 아래로 떨어지면 「수정 후 재심사」로 모든 공격이 빨라진다.
- 보스가 여럿이면 체력 막대가 모두 위에서 아래로 쌓여 보인다 (먼저 나온 보스가 위, 4마리 넘으면 '+n').
- 가시성: 적의 공격은 붉은 테두리로 맨 위에, 내 무기 효과는 조금 연하게 그린다 (`js/world.js` 의 `MY_AREA` · `MY_SHOT`)
- 기본 무기를 Lv 8까지 올리면 진화: 펜→교수님의 빨간펜, 마우스→게이밍 마우스, 키보드→기계식 키보드(청축), 개인 PC→워크스테이션, 피펫→멀티채널 피펫, 시약병→과망간산칼륨, 분젠 버너→오토클레이브, 실험쥐→유전자 변형쥐, 전공서적→학위논문, 파리채→전기 모기채, 클로드→클로드 코드, GPT→Codex, 제미나이→(진화 없음)
- 성소(자주 열리는 순): 헬스장 → 증바람 → 회식 → 학회 출장 → 풋살

## 온라인 기록판 (최고 기록 공유)

타이틀의 **🏆 기록판**에서 모든 플레이어의 최고 연구 실적 · 박사 최장 생존 TOP 10을 보고, 결과 화면에서 닉네임과 함께 기록을 올립니다.
서버는 `api/scores.js` (Vercel 서버리스 함수)이고, 기록은 Upstash Redis(무료)에 저장됩니다. 처음 한 번만 설정하면 됩니다.

1. GitHub에 `api` 폴더째 `api/scores.js` 를 올린다.
2. Vercel 대시보드 → 프로젝트(grad-survival) → **Storage** 탭 → **Create Database** → **Upstash for Redis**(Free) → 이 프로젝트에 **Connect**.
3. **Settings → Environment Variables** 에 `UPSTASH_REDIS_REST_URL` · `UPSTASH_REDIS_REST_TOKEN` (또는 `KV_REST_API_URL` · `KV_REST_API_TOKEN`)이 생겼는지 확인. 이름 앞에 접두사(예: `STORAGE_`)가 붙어도 된다.
4. **Deployments** → 최신 배포 **Redeploy** (환경 변수는 새 배포부터 적용됨).
5. 사이트 타이틀 → 🏆 기록판에서 "아직 기록이 없어요"가 보이면 연결 완료.

- 비밀 토큰은 서버 함수에서만 쓰고 브라우저로 보내지 않는다. 닉네임은 12자까지, 같은 IP는 1분에 8번까지 올릴 수 있다.
- 점수는 브라우저가 보내는 값이라 마음먹고 조작하면 막을 수 없다 (수업용 기록판 수준).
- `index.html` 을 더블클릭해 열거나 로컬 서버에서 열면 기록판 대신 "연결할 수 없어요"가 보이고, 이 브라우저의 내 기록만 보인다.

## 밸런스 시뮬레이터

`tools/sim.html`을 열고 개발자 도구(F12) 콘솔에서 실행합니다. 봇이 16분 게임을 빠르게 수십 판 돌려 결과를 요약합니다.

```js
GS.Sim.start(GS.Sim.plan({ seeds: 4, modes: ['normal', 'runner'] }))   // chars: ['wet'] 로 캐릭터만 골라 돌릴 수도 있음
GS.Sim.work(20000)   // 끝날 때까지 반복
GS.Sim.summary()
```

- `normal`: 적을 피하면서 지식·성소를 챙기는 플레이어
- `runner`: 싸움을 피하고 도망만 다니는 플레이어

## 게임 소개 영상

- 타이틀 화면의 **🎬 소개 영상** 버튼으로 재생합니다 (ESC 건너뛰기, Space·클릭 일시정지, ←→ 5초씩 앞뒤로, 끝나면 타이틀로).
- `media/intro.mp4` 가 있으면 그 영상을 틀고, 없으면 게임 엔진으로 직접 그리는 기본 소개 영상(`js/intro.js`)을 틉니다.
- 기본 소개 영상은 발표용 플레이 설명 영상(약 57초)입니다: 타이틀 → 캐릭터(Dry lab · Wet lab, 화면 반반, 전용 무기) → 기본 플레이(자동 공격·지식·레벨업 카드) → 진화 → 보스 패턴 4분할(기말고사 OMR · 킥오프 로켓 발진 · 포스터 질문 행렬 · 졸업논문 심사 발표자 조명을 한 화면에) → 학기 진행 → 결말(취업 / 박사 과정) → 박사 과정(무한 웨이브·2분마다 보스) → 마무리. 자막은 명사형으로 끝냅니다. 소리는 없습니다.
- 기본 소개 영상의 장면은 `js/intro.js` 의 `SCENES` 에서 고칩니다. `tools/intro.html` 을 크롬·엣지로 열고 **MP4 만들기** 를 누르면 같은 영상을 MP4 파일로 내려받을 수 있어요.
- 직접 편집한 영상을 쓰려면 파일 이름을 `intro.mp4` 로 해서 `media/` 폴더에 넣으면 됩니다.

## 테스트용 URL 옵션

- `index.html?start=pen` 메뉴 건너뛰고 바로 시작. 무기로 캐릭터가 정해짐 (Dry lab `pen` / `mouse` / `keyboard` / `pc`, Wet lab `pipette` / `flask` / `bunsen` / `labmouse`)
- `index.html?char=wet` 그 캐릭터로 바로 시작 (`dry` / `wet`, 무기는 무작위)
- `index.html?demo` 봇 자동 플레이 (발표 시연용), `&speed=4` 빨리 감기, `&seed=123` 난수 고정
