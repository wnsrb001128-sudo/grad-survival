# 대학원에서 살아남기

뱀파이어 서바이벌류(뱀서라이크) 웹 게임. 대학원생이 석사 4학기를 버티고 취업하는 이야기입니다.

## 실행

- `index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다 (설치 불필요, 크롬·엣지 권장).
- 조작: **WASD** 이동 (공격은 자동) · 레벨업 카드 **1~4 / 클릭** · **ESC** 일시정지 · **M** 소리 켜기/끄기

## 규칙

| 웨이브 | 내용 | 보스 |
|---|---|---|
| 1차 · 석사 1학기 (0~4분) | 대학원 수업, 교수님 심부름, 개인 프로그레스 미팅, 중간고사 | 중간보스 감기, 보스 기말고사 |
| 2차 · 석사 2학기 (4~8분) | LA, TA, OA, 주간 랩미팅, 컴퓨터 강제 종료(윈도우 업데이트), 시험 채점, 플롯 그리기 | 과제 킥오프 미팅 |
| 3차 · 석사 3학기 (8~12분) | 과제 미팅, 메이저 리비전, 버그, 시뮬레이션 발산(NaN), 어학 성적 취득 | 학회 포스터 발표 |
| 4차 · 석사 4학기 (12~16분) | 과제 제안서 작성, Reviewer #2, 마감 | 학회 구두 발표 |

- 4차가 끝날 때 **연구 실적 40,000 이상 → 취업 엔딩**, 미만이면 **박사 과정** (시간 제한 없는 무한 웨이브)
- 기본 무기를 Lv 8까지 올리면 진화: 펜→교수님의 빨간펜, 마우스→게이밍 마우스, 키보드→기계식 키보드(청축), 개인 PC→워크스테이션, 전공서적→학위논문, 클로드→클로드 코드, GPT→Codex, 제미나이→(진화 없음)
- 성소(자주 열리는 순): 헬스장 → 증바람 → 회식 → 학회 출장 → 풋살

## 밸런스 시뮬레이터

`tools/sim.html`을 열고 개발자 도구(F12) 콘솔에서 실행합니다. 봇이 16분 게임을 빠르게 수십 판 돌려 결과를 요약합니다.

```js
GS.Sim.start(GS.Sim.plan({ seeds: 4, modes: ['normal', 'runner'] }))
GS.Sim.work(20000)   // 끝날 때까지 반복
GS.Sim.summary()
```

- `normal`: 적을 피하면서 지식·성소를 챙기는 플레이어
- `runner`: 싸움을 피하고 도망만 다니는 플레이어

## 테스트용 URL 옵션

- `index.html?start=pen` 메뉴 건너뛰고 바로 시작 (`pen` / `mouse` / `keyboard` / `pc`)
- `index.html?demo` 봇 자동 플레이 (발표 시연용), `&speed=4` 빨리 감기, `&seed=123` 난수 고정
